# Hi, I'm Bhargav Chintam

Applied machine learning and data engineering, about six years across genomics, clinical analytics, telecom and enterprise data. M.S. in Computer Science. I like problems where the data has coordinates.

## Geospatial portfolio

Six end-to-end QGIS + Python projects. Each runs on one command, has an interactive map, a Streamlit dashboard, QGIS styles and a Processing Toolbox script, and is covered by CI.

Portfolio site: https://bhargavchintam.github.io/qgis-geospatial-projects/

| Project | What it does | Key result |
|---|---|---|
| [Urban Heat Island Analysis](https://github.com/bhargavchintam/qgis-geospatial-projects/tree/main/urban-heat-island-analysis) | Landsat thermal to LST, UHI zones, mitigation priority map | LST vs impervious r = 0.82, 378 ha high priority |
| [Flood Risk Assessment](https://github.com/bhargavchintam/qgis-geospatial-projects/tree/main/flood-risk-assessment) | DEM hydrology, 7-criteria AHP, vulnerability, risk scenarios | 7 % of area high risk, 10,202 people exposed |
| [Crop Health Monitoring](https://github.com/bhargavchintam/qgis-geospatial-projects/tree/main/crop-health-ndvi-monitoring) | Sentinel-2 season, phenology fitting, stress anomalies, field reports | 2.7 % stressed area, 4 of 4 N-stressed fields flagged |
| [Healthcare Access Analysis](https://github.com/bhargavchintam/qgis-geospatial-projects/tree/main/healthcare-access-analysis) | Road-network isochrones, 2SFCA, facility site selection | 89 % to 100 % coverage with 2 new sites |
| [Forest Change Detection](https://github.com/bhargavchintam/qgis-geospatial-projects/tree/main/forest-change-detection) | Random Forest land cover, change detection, accuracy assessment | 44.8 ha loss mapped, OA 0.98, kappa 0.97 |
| [Solar Site Suitability](https://github.com/bhargavchintam/qgis-geospatial-projects/tree/main/solar-site-suitability) | Terrain, AHP overlay, constraints, ranked parcels with MW | 10 sites, 1,911 MW developable |
