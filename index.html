Run any project yourself

No accounts, no downloads. Each demo builds a realistic georeferenced synthetic scene, runs the real pipeline code and writes rasters, vectors, figures and a web map.

git clone https://github.com/bhargavchintam/qgis-geospatial-projects.git
cd qgis-geospatial-projects/flood-risk-assessment   # or any other project
pip install -r requirements.txt
python demo.py              # 2 to 10 seconds
streamlit run app.py        # interactive dashboard
python -m pytest tests -q   # tests

To use real data, point each project's config.yaml at your own rasters and vectors. Every README lists the public sources (USGS, Copernicus, NOAA, NLCD, Census, OpenStreetMap, NREL, HIFLD).
